# Pozemky Košice – mapa

Mapa stavebných pozemkov v okolí Košíc s ortofotom SR, satelitom a odkazmi na kataster ZBGIS.

- Web: https://lukasmax1.github.io/pozemky-mapa_LM/
- Údaje (`data.json`) automaticky aktualizuje denné hľadanie v aplikácii *Pozemky Košice* v Claude.
- Obsahuje len údaje z verejných inzerátov; poznámky a stavy sem nejdú.

Mapové podklady: Ortofotomozaika SR © ÚGKK SR, NLC (cez freemap.sk), Esri World Imagery, © OpenStreetMap, OpenTopoMap.
